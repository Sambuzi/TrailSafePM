# TrailSafe - Project Management

Repository dell'elaborato di Project Management per TrailSafe, piattaforma web per la sicurezza sui sentieri escursionistici.

## Struttura

- `01_Descrizione_Approccio/`: relazione principale sull'approccio utilizzato.
- `02_Documentazione_Progetto/`: documentazione operativa divisa per fasi di progetto.
