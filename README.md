# TrailSafe - Elaborato di Project Management

## 📌 Descrizione
**TrailSafe** è la simulazione della gestione completa di un progetto (dall'avvio alla chiusura) per una piattaforma web dedicata alla sicurezza e consultazione dei sentieri escursionistici, commissionata da un Ente Parco territoriale. L'obiettivo dell'elaborato è documentare il framework di management per il rilascio di un **MVP** (area pilota di 20-30 sentieri).

* **Durata:** ~5 mesi
* **Budget:** € 75.000
* **Approccio:** **Ibrido** (Predittivo per Scope/Budget e Agile/Iterativo per lo sviluppo in 5 Sprint).
