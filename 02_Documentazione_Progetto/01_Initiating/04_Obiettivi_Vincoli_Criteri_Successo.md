# Obiettivi, vincoli e criteri di successo

## Obiettivi SMART

| ID | Obiettivo | Misurabilita | Scadenza |
| - | - | - | - |
| O1 | Rilasciare un MVP web di TrailSafe | Piattaforma accessibile da browser e approvata dal committente | 31/08/2026 |
| O2 | Digitalizzare le informazioni essenziali sui sentieri dell'area pilota | Almeno 20 sentieri inseriti con dati principali | 20/07/2026 |
| O3 | Consentire agli utenti di inviare segnalazioni | Modulo segnalazione funzionante e collegato al pannello amministrativo | 20/07/2026 |
| O4 | Abilitare la gestione amministrativa | Area riservata per sentieri, stati, avvisi e segnalazioni | 20/07/2026 |
| O5 | Migliorare la comunicazione di avvisi e stati percorso | Stato percorso e avvisi visibili nelle schede sentiero | 20/07/2026 |

## Vincoli

| ID | Vincolo | Descrizione |
| - | - | - |
| V1 | Tempo | Il progetto deve concludersi entro 6 mesi |
| V2 | Budget | Il budget simulato massimo e pari a 75.000 euro |
| V3 | Ambito | Il rilascio riguarda un MVP limitato a un'area pilota |
| V4 | Tecnologia | La soluzione deve essere fruibile da browser web |
| V5 | Dati | L'ente deve fornire informazioni iniziali sui sentieri |
| V6 | Didattica | La documentazione deve rispettare le fasi richieste dall'elaborato |

## Assunzioni

- I dati sui sentieri sono disponibili in formato utilizzabile.
- Il committente collabora nelle fasi di validazione.
- Le funzionalita avanzate non essenziali vengono escluse dall'MVP.
- Il team dispone delle competenze necessarie per sviluppo web, UX, test e project management.

## Criteri di successo

| ID | Criterio | Valore atteso |
| - | - | - |
| CS1 | Rispetto tempi | Chiusura progetto entro il 31/08/2026 |
| CS2 | Rispetto budget | Costo complessivo non superiore a 75.000 euro |
| CS3 | Copertura contenuti | Almeno 20 sentieri disponibili nell'MVP |
| CS4 | Funzionalita utente | Consultazione mappa, schede sentiero, stati e avvisi |
| CS5 | Segnalazioni | Invio e visualizzazione delle segnalazioni in area amministrativa |
| CS6 | Funzionalita amministrative | Gestione di sentieri, stati, avvisi e segnalazioni |
| CS7 | Qualita percepita | Interfaccia comprensibile e adatta a utenti non tecnici |
| CS8 | Accettazione | Approvazione finale da parte del committente simulato |

## Priorita iniziali

| Priorita | Elemento |
| - | - |
| Alta | Mappa sentieri, schede percorso, stato sentiero, area amministrativa base, segnalazioni |
| Media | Meteo, avvisi, moderazione avanzata, dashboard amministrativa |
| Bassa | Funzioni social, profilo utente avanzato, preferiti evoluti, espansione multi-area |
